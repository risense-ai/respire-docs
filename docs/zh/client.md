# 客户端 {#client}

Respire Client 2 是使用 Go 和 Wails v3 构建的桌面应用，构建目标包括 Windows、macOS 和 Linux。Windows amd64 已做本机交互验证；非 Windows 的界面、托盘、登录集成和自动更新仍需原生验收。内嵌界面与托管的[控制台](product/web.md)相互独立。客户端通过本机环回 RPC 连接 CLI Runtime，并通过受限宿主操作处理账户切换、注入和凭据配置。客户端不包含 Core 或模型权重。

从[客户端发布页](https://github.com/risense-ai/respire-client2/releases)下载匹配的应用。客户端单独下载匹配的 CLI 和原生运行时，也可连接已有的兼容本机 Runtime。桌面端和 CLI 分别选择 Stable 或 Dev 更新通道。桌面端可构建不代表匹配的 CLI 发布一定可用；见[平台支持](https://github.com/risense-ai/respire-client2/blob/main/docs/platforms.md)。

## 页面与托盘 {#pages-and-tray}

| 页面 | 操作与条件 |
|---|---|
| 总览 | 查看本机和云端数量、待同步项、冲突、索引、模型任务及 Runtime 状态；同步，以及启动或停止 Runtime。 |
| 记忆 | 使用树、列表、卡片或图谱浏览；筛选已载入条目或检索记忆库；读取、创建、编辑、移动、合并、复制、删除、恢复、分享和查看因果链。编辑器提供三段正文模板和相近记忆查询，可查看候选并选为父节点，也可明确跳过判重。工具包括提升一级、检查授权、成书/画像/子树材料，以及永久清除密文。 |
| 日记 | 按月或日浏览、跨日期搜索，并打开片段和相邻内容。 |
| 整理 | 查看归纲建议、相似记忆和结构检查；生成、编辑、复制、预览并应用校验后的本地移动方案；逐条或批量预览建议。配置服务后，可按条数、子树或全库预览或执行 AI 整理。 |
| 模型与索引 | 选择下载源、准备或下载权重、取消 Runtime 中的模型任务或卸载模型；选择已下载权重和引擎、安装 NPU 提供程序、验证推理、准备或重建索引、配置召回，并运行召回检查和九轮 Benchmark。可重新下载权重；应用引擎会重载模型并验证推理，失败时自动回退 CPU。 |
| 账户与空间 | 浏览器或密码登录、注册、恢复、重置超级密码、初始化离线库、导出密钥和退出；切换账户、检查或迁移旧账户、配置服务器和同步、查看冲突，以及创建、加入、切换或删除空间并管理邀请和成员。密码操作需要支持账户 RPC 的兼容 CLI；登录支持填写两步验证代码。可撤销单个或全部成员访问。 |
| 配置Agent | 选择提示词模式、检测目标、注入或移除提示词，以及准备或安装宿主插件。切换提示词模式会重写所有已启用 Agent 的提示词，但不改变插件；关闭单个 Agent 会移除注入内容，保留插件。部分插件需要在宿主界面完成安装。DSH 提示词注入会覆盖 `~/.dsh/AGENTS.md`，并移除该路径上的符号链接；请先检查并备份目标。 |
| 访问授权 | 创建、查看和撤销子树只读授权，包括检查继承的访问权限。 |
| 设置 | 修改主题、布局、语言、登录启动、自动连接 Runtime、自动更新、通道、工作和日记模式及数据目录；导入/导出记忆、备份数据库、导入分享材料和导入/导出客户端设置。 |
| 更新 | 分别设置客户端与 Runtime 的自动更新和检查频率；检查、下载、取消和应用客户端更新，也可检查、安装或更新 CLI。启用自动重启后，客户端可在下载完成且没有业务操作时重启。 |
| 操作 | 查看写入状态、请求 ID 和本次会话的回执；结果未知时查询原请求。宿主操作的结果须在对应页面检查。 |
| 诊断 | 查看连接和健康状态，运行 CLI doctor 并导出诊断。 |
| 托盘 | 快捷面板显示状态，可同步或打开主窗口。面板可手动刷新，也会在获得焦点或重新显示时刷新。菜单可启动或停止 Runtime、检查更新，以及退出客户端并保留 Runtime。 |

图谱每页最多显示 300 个节点，支持查看跨页关系、缩放、平移、选择和拖动节点。可用“定位所选”居中，也可聚焦节点后按 Enter 或空格打开。目录筛选仅作用于已载入的记忆。记忆页快捷键包括 Ctrl/Command+K 搜索、Ctrl/Command+N 新建、Ctrl/Command+Z 撤销符合条件的操作，Ctrl/Command+Shift+N 为所选节点新建后续记忆，以及 Ctrl/Command+Shift+C 复制节点链接。F2 编辑，Delete 或 Backspace 删除；方向键选择、展开或折叠节点。打开对话框或正在编辑输入控件时，这些快捷键不触发。撤销只保留一个符合条件的操作；记忆库发生变化时会拒绝撤销，且它不是跨客户端原子事务。

## 界面操作说明 {#screen-walkthrough}

页面和托盘截图通过浏览器运行 Client 2 前端，并使用模拟数据。更新页、记忆编辑和合并截图来自 0.2.25，其余截图来自 0.2.24。账户、数量和任务状态均为示例。这些图片用于说明界面，不代表各平台的原生验收结果。

### 概览与托盘 {#overview-and-tray}

打开“概览”，可以检查 Runtime 连接、本地和云端数量、待同步项与模型任务。配置云账户后，可以选择“立即同步”。显示的数量和冲突取决于当前账户与空间。

首次配置时，“开始使用”会列出 Runtime、账户、本机密钥和 Agent 配置的状态。纯本地使用不要求登录，登录项可能仍显示未完成。密钥项只检查本机是否存在密钥，不能证明恢复材料已经备份。

![概览中的 Runtime、同步与模型状态](/client2/overview-zh.png)

托盘快捷面板也显示这些状态，并提供“立即同步”和“打开 Respire”。托盘菜单还提供 Runtime 和更新操作。关闭窗口会隐藏界面；退出客户端不会停止 Runtime。

![托盘快捷面板](/client2/quickpanel-zh.png)

### 记忆与日记 {#memories-and-diary}

在“记忆”页选择树形、列表、卡片或图谱。选中条目可以阅读正文；选择“新建记忆”可以写入内容。目录筛选只处理已载入的条目；要搜索整个库，请使用全库检索。选择父节点、合并或跳过判重前，请先查看相似条目。

树形和列表中，点击标题打开正文，点击行的其他位置选择条目。按住 Ctrl（macOS 为 Command）可多选，按住 Shift 可选取可见范围；选中多个条目后可以使用“合并所选”。全库检索最多返回 50 条结果。

目录筛选支持类型、存储区域、项目和标签，也可以调整排序；项目和标签按完整值匹配。列表尚未全部载入时，使用“载入更多”继续浏览。这些筛选只作用于已载入条目。客户端在空闲时约每 30 秒尝试重新读取目录，显示的结果取决于读取状态。

支持元数据列表的 Runtime 会让客户端尝试补全记忆目录，最多请求 100,000 条。侧栏布局下，可以拖动侧栏边缘调整宽度；在记忆页，也可以拖动目录与阅读区之间的分隔线。图谱模式下不能调整该分隔线。

删除后，当前页面提供“恢复刚才删除的记忆”。如果该入口不再显示，可以使用兼容的 CLI 和原始 ID 恢复；永久清除密文则无法撤销。

![记忆树与搜索](/client2/memories-zh.png)

新建时可填写类型、存储区域、父节点、正文和标签。使用“查找相近记忆”检查候选；只有确认需要独立创建时，才勾选跳过判重。

![记忆编辑器](/client2/memory-editor-zh.png)

合并时，编辑器会将选中条目的标题和正文拼入待保存内容。请核对完整内容和父节点；确认合并后，旧条目会被替换，未选中的子节点会提升到仍存在的祖先，不会自动挂到新条目。

![合并记忆的编辑与提醒](/client2/memory-merge-zh.png)

撤销只适用于最近一次符合条件的操作，包括结果为 `created` 的主区新建、主区内编辑、删除或移动。日记新建、跨存储区域编辑和合并不支持这个撤销；撤销前应先核对当前内容。

在“日记”页可以按月或日浏览，搜索日期，并打开片段及相邻内容。“整理”页提供归类、相似项与结构检查；应用移动方案前，请先预览。AI 整理需要配置服务，并会向该服务发送所选材料。

日记搜索使用查询内容查找片段；选择结果旁的“展开”可查看相邻片段。整理方案在编辑后需要重新预览；如果记忆库在预览后发生变化，也需要重新生成或校验方案。AI 方案预览不会执行变更，而“AI 整理并执行”会在确认后提交变更。

### 模型与索引 {#models-and-index}

打开“模型与索引”查看模型和索引任务。页面支持选择下载源、准备权重和选择可用的推理引擎，也提供推理验证、索引准备、召回设置与九轮基准测试。权重需要单独下载；可用的引擎和提供程序取决于 Runtime 与硬件。

先下载所需权重，再选择引擎并应用。应用时客户端会重载模型并验证推理；验证失败时会回退到 CPU。Linux 界面只提供 CPU 引擎，安装 NPU 引擎的按钮仅在 Windows 可用。下载或索引任务进行时，可以在页面查看状态和进度。

页面还可以配置高质量召回服务、切换召回方式、安排后台索引和重新计算向量。基准测试可以在当前请求返回后停止后续轮次；卸载模型会移除模型文件，需要时须重新下载。

下载基础模型和单个权重时，客户端会使用并行下载。基础文件就绪后，模型页会尝试安排索引；请查看页面显示的结果。“取消当前任务”针对 Runtime 报告的模型任务，不能据此认为它能取消客户端下载。

### 连接 Agent 与管理授权 {#connect-agents-and-manage-access}

在“配置Agent”页检查目标，选择提示词模式，再启用 Agent。请查看操作结果；如果宿主要求额外安装或审阅钩子，还需要在宿主内完成。关闭 Agent 会移除注入内容，但保留插件；切换模式会重写已启用 Agent 的提示词。注入 DSH 前，请检查并备份目标路径。每个宿主的步骤见[插件页面](plugins/)。

选择 Agent 旁的“详情”可查看目标路径和插件信息。开启开关可能直接修改目标文件，因此应在操作前检查已有内容。客户端 0.2.25 的配置页面不提供 Codex 文件预览。

列表默认折叠部分目标；选择“显示其余”可以查看。提示词模式包含正常、只读和关闭，选定后需选择“应用并更新已启用的提示词”。

![配置 Agent 页面的提示词模式和 Agent 列表](/client2/injection-zh.png)

在“访问授权”页可以查看、创建或撤销记忆子树的只读授权，也可以检查继承的权限。邀请和授权可能带来数据访问能力，请只分享给可信人员。

新建授权时，需要填写子树根节点 ID 和工具或用途。授权包含该节点的后代；撤销后，使用该令牌的工具将无法继续读取授权范围。

创建后，客户端会显示授权材料。请安全保存令牌，并只交给可信工具。要检查某条记忆的直接授权和继承授权，请在记忆页选中它，再选择“查看访问授权”。移动记忆后，它继承的授权范围可能改变，请重新检查。

### 设置、更新与诊断 {#settings-updates-and-diagnostics}

在“设置”页调整外观、语言、启动方式和 Runtime 连接，也可以导入或导出数据。“更新”页分别管理桌面端和 CLI；应用更新前，请检查各自的通道和下载状态。“操作记录”显示请求 ID 与本次会话回执，“诊断”显示连接状态并支持导出诊断。分享诊断文件前，请先检查内容。

写操作显示“结果未确认”时，在“操作记录”中选择“查询原请求”，再到对应页面核对数据。客户端重启后，完整回执不再保留。诊断页可以运行检查，也可以选择保存位置导出诊断文件。

设置页还提供工作区模式、日记记录方式、字体和阅读排版。界面语言与 CLI 显示语言分别设置。客户端设置备份不包含记忆密钥；记忆导出和数据库备份需要分别保存。

在“更新”页，可以分别设置客户端自动下载、客户端自动重启，以及受客户端管理的 Runtime 自动安装和自动重启。客户端与 Runtime 的检查频率也可分别设置。关闭客户端自动重启后，下载完成时需要手动选择客户端一栏的“重启并应用”；业务操作进行期间不会应用客户端更新。

关闭 Runtime 自动重启后，安装的新版本会在下次启动 Runtime 时生效；按钮可用时，也可以选择 CLI / Runtime 一栏的“重启并应用”。请检查页面显示的当前运行版本。桌面客户端和 CLI / Runtime 的发布通道可分别选择；切换通道不会自动降级已安装的版本。

## 数据与失败边界 {#data-and-failure-boundaries}

记忆 JSON 导出和分享材料包含明文。密钥导出和恢复材料可以解锁数据；空间邀请包含访问和解密能力。请保护这些文件，仅与可信人员分享。删除空间会删除对应的本机空间及数据。“忘记本机身份”会移除会话和解密材料，但保留记忆密文；再次解锁需要恢复材料。切换数据目录时，原目录保留，记忆和密钥不会自动复制；新目录需要自己的会话和密钥。普通记忆删除可通过同步传播；永久清除密文不可撤销。合并会替换源条目，未选中的子节点按 Runtime 规则提升。

AI 整理会向配置的服务发送选定记忆材料。高质量召回会发送查询和候选标题。服务密钥通过标准输入传给 CLI，由 CLI 存入系统凭据库。诊断导出可能包含本机路径、操作错误和完整会话回执；分享前请检查。

写入回执丢失并不证明写入失败。客户端保留请求 ID，查询原请求，不会自动重放。完整回执保留在当前会话中；重启后只保留请求元数据。旧版 Runtime 或 CLI 可能不支持部分功能；缺少发布资产时，客户端会报告错误，不会下载其他架构的资产。

切换数据目录后，如果页面提示设置已保存但尚未确认 Runtime 切换，请刷新诊断并核对当前目录，不要重复提交。

## 打包边界 {#packaging-boundary}

Windows 使用可执行文件，需要 WebView2。macOS 应用包需要 macOS 12 或更高版本；Linux 需要 GTK 3、WebKitGTK 4.1、X11 客户端库及兼容 Ubuntu 22.04 的系统库，不能直接用于 Alpine/musl。桌面应用与 CLI/原生运行时分别分发。请核对平台依赖和发布资产；客户端不包含模型权重。见 [Windows 打包](windows-packaging.md)和[客户端集成](CLIENT-GUIDE.md)。
