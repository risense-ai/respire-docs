# 客户端 {#client}

Respire Client 2 是使用 Go 和 Wails v3 构建的桌面应用，构建目标包括 Windows、macOS 和 Linux。Windows amd64 已做本机交互验证；非 Windows 的界面、托盘、登录集成和自动更新仍需原生验收。内嵌界面与托管的[控制台](product/web.md)相互独立。客户端通过本机环回 RPC 连接 CLI Runtime，并通过受限宿主操作处理账户切换、注入和凭据配置。客户端不包含 Core 或模型权重。

从[客户端发布页](https://github.com/risense-ai/respire-client2/releases)下载匹配的应用。客户端单独下载匹配的 CLI 和原生运行时，也可连接已有的兼容本机 Runtime。桌面端和 CLI 分别选择 Stable 或 Dev 更新通道。桌面端可构建不代表匹配的 CLI 发布一定可用；见[平台支持](https://github.com/risense-ai/respire-client2/blob/main/docs/platforms.md)。

## 页面与托盘 {#pages-and-tray}

| 页面 | 操作与条件 |
|---|---|
| 总览 | 查看本机和云端数量、待同步项、冲突、索引、模型任务及 Runtime 状态；同步，以及启动或停止 Runtime。 |
| 记忆 | 使用树、列表、卡片或图谱浏览；筛选已载入条目或检索记忆库；读取、创建、编辑、移动、合并、复制、删除、恢复、分享和查看因果链。编辑器提供三段正文模板和相近记忆查询，可查看候选并选为父节点，也可明确跳过判重。工具包括提升一级、检查授权、成书/画像/子树材料，以及永久清除密文。 |
| 日记 | 按月或日浏览、跨日期搜索，并打开片段和相邻内容。 |
| 整理 | 查看归纲建议、相似记忆和结构检查；生成、编辑、复制、预览并应用校验后的本地移动方案；逐条或批量预览建议。配置服务后，可按条数、子树或全库预览或执行 AI 整理。 |
| 模型与索引 | 选择下载源、准备或下载权重、取消任务或卸载模型；选择已下载权重和引擎、安装 NPU 提供程序、验证推理、准备或重建索引、配置召回，并运行召回检查和九轮 Benchmark。可重新下载权重；应用引擎会重载模型并验证推理，失败时自动回退 CPU。 |
| 账户与空间 | 浏览器或密码登录、注册、恢复、重置超级密码、初始化离线库、导出密钥和退出；切换账户、检查或迁移旧账户、配置服务器和同步、查看冲突，以及创建、加入、切换或删除空间并管理邀请和成员。密码操作需要支持账户 RPC 的兼容 CLI；登录支持填写两步验证代码。可撤销单个或全部成员访问。 |
| 安装 | 选择并分发提示词模式、检测目标、注入或移除提示词，以及准备或安装宿主插件。当前界面为 Codex 提供文件预览；应用时需要预览修订号。切换提示词模式会重写所有已启用 Agent 的提示词，但不改变插件；关闭单个 Agent 会移除注入内容，保留插件。部分插件需要在宿主界面完成安装。DSH 提示词注入会覆盖 `~/.dsh/AGENTS.md`，并移除该路径上的符号链接；请先检查并备份目标。 |
| 访问授权 | 创建、查看和撤销子树只读授权，包括检查继承的访问权限。 |
| 设置 | 修改主题、布局、语言、登录启动、自动连接 Runtime、自动更新、通道、工作和日记模式及数据目录；导入/导出记忆、备份数据库、导入分享材料和导入/导出客户端设置。 |
| 更新 | 检查、下载、取消和应用客户端更新；检查、安装或更新 CLI，也可打开发布页和镜像。启用自动更新后，下载完成且没有业务操作时，客户端可能自动重启。 |
| 操作 | 查看写入状态、请求 ID 和本次会话的回执；结果未知时查询原请求。宿主操作的结果须在对应页面检查。 |
| 诊断 | 查看连接和健康状态，运行 CLI doctor 并导出诊断。 |
| 托盘 | 快捷面板显示状态，可同步或打开主窗口。面板可手动刷新，也会在获得焦点或重新显示时刷新。菜单可启动或停止 Runtime、检查更新，以及退出客户端并保留 Runtime。 |

图谱每页最多显示 300 个节点，支持查看跨页关系、缩放、平移、选择和拖动节点。可用“定位所选”居中，也可聚焦节点后按 Enter 或空格打开。目录筛选仅作用于已载入的记忆。记忆页快捷键包括 Ctrl/Command+K 搜索、Ctrl/Command+N 新建、Ctrl/Command+Z 撤销符合条件的操作，Ctrl/Command+Shift+N 为所选节点新建后续记忆，以及 Ctrl/Command+Shift+C 复制节点链接。F2 编辑，Delete 或 Backspace 删除；方向键选择、展开或折叠节点。打开对话框或正在编辑输入控件时，这些快捷键不触发。撤销只保留一个符合条件的操作；记忆库发生变化时会拒绝撤销，且它不是跨客户端原子事务。

## 数据与失败边界 {#data-and-failure-boundaries}

记忆 JSON 导出和分享材料包含明文。密钥导出和恢复材料可以解锁数据；空间邀请包含访问和解密能力。请保护这些文件，仅与可信人员分享。删除空间会删除对应的本机空间及数据。“忘记本机身份”会移除会话和解密材料，但保留记忆密文；再次解锁需要恢复材料。切换数据目录时，原目录保留，记忆和密钥不会自动复制；新目录需要自己的会话和密钥。普通记忆删除可通过同步传播；永久清除密文不可撤销。合并会替换源条目，未选中的子节点按 Runtime 规则提升。

AI 整理会向配置的服务发送选定记忆材料。高质量召回会发送查询和候选标题。服务密钥通过标准输入传给 CLI，由 CLI 存入系统凭据库。诊断导出可能包含本机路径、操作错误和完整会话回执；分享前请检查。

写入回执丢失并不证明写入失败。客户端保留请求 ID，查询原请求，不会自动重放。完整回执保留在当前会话中；重启后只保留请求元数据。旧版 Runtime 或 CLI 可能不支持部分功能；缺少发布资产时，客户端会报告错误，不会下载其他架构的资产。

## 打包边界 {#packaging-boundary}

Windows 使用可执行文件，需要 WebView2。macOS 使用应用包；Linux 需要 GTK 3、WebKitGTK 4.1 和平台库。桌面应用与 CLI/原生运行时分别分发。请核对平台依赖和发布资产；客户端不包含模型权重。见 [Windows 打包](windows-packaging.md)和[客户端集成](CLIENT-GUIDE.md)。
